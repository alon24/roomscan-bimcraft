Make the files

Open it in BIMCraft

  1. Correct the plan here. It saves by itself.
  2. Press Build BIMCraft and Blender files.
  3. Download room.bimcraft.
  4. In a terminal: bimcraft ~/Downloads/room.bimcraft

Open it in Blender

  1. Download layout.glb.
  2. File → Import → glTF 2.0, and pick it. Sizes are in metres. Doors and windows aren't cut out.
